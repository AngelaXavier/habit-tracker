<h1 align="center"> BLOOM </h1> 

<h2> Descrição do projeto</h2>

<h5>  Projeto em desenvolvimento para a disciplina Programação Web 1 do curso Análise e Desenvolvimento de Sistemas. O Bloom é um site de rastreamento de hábitos.
<br>
  Ele vai permitir que o usuário consiga acessar sua rotina, adicionar hábitos, consulta-los e verificar seu próprio progresso.
</h5>

<h5 align="center">  
:construction:  Projeto em construção  :construction: 
</h5>

# :hammer: Funcionalidades do projeto 
- `Funcionalidade 1`: O projeto deve ser capaz de adicionar hábitos, altera-los e exclui-los, tendo botões para essa funcionalidade.
- `Funcionalidade 2`: É necessário que o site apresente o progresso do usuário, sua evolução semanal, quantos dias ele está fazendo consecutivos do hábito, acompanhando a evolução do usuário.
- `Funcionalidade 3`: Deve ser possível escolher a categoria do hábito, sendo exemplo delas: cultura, exercício, saúde entre outros.
